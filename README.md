# 🌐 Weather Sphere

Weather Sphere is a sleek, responsive weather application built using **HTML**, **CSS**, and **JavaScript** with powerful API integration. It features real-time weather updates, an interactive UI, dark/light modes, and detailed forecasts, making it your perfect daily weather companion.

---

## 🚀 Features

- Real-time weather data using API integration
- Beautiful, responsive, and mobile-friendly UI
- 48-hour hourly forecast with horizontal scroll navigation
- 3-day detailed forecast for better planning
- Dark mode and Light mode toggle for optimal viewing
- Smooth transitions and modern design

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript 
- Weather API Integration
